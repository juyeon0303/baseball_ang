    야구주식이 뭐예요?

    KBO·MLB 선수 기록과 팬 화제에 가상 포인트로 「된다 / 안 된다」를 겨루는 야구 팬 게임이에요. 진짜 주식은 아닙니다.

    무엇에 베팅하나요?
    • 구단 대표 종목 10개 — 팀별 화제 선수 (OPS·ERA 기준 시세)
    • 이정후 (MLB) — KBO 10구단과 별도 종목, MLB OPS 반영
    • 밈·화제 베팅 — 예: 김서현 직구 제구, 강백호 50홈런 달성
    선수 기록 자동 반영 경기 점수 연동 주간 랭킹
    이렇게 쓰면 됩니다
    1. 닉네임 입력 → 시작 포인트 10만 P
    2. 종목이나 밈 카드를 눌러 「지금 베팅」 영역 확인
    3. 된다! = 잘 될 것 같다 · 안 된다 = 아닐 것 같다
    4. 경기 카드에서 라이브 경기·타석 소식 확인 (연동 종목 자동 전환)
    5. 주간 수익률 랭킹으로 1위 경쟁
    가격은 왜 움직이나요?
    • 기록 반영 — KBO/MLB 공식 기록 (하루 1회 갱신)
    • 된다 쪽 — 「된다」 베팅이 많아지면 시세 상승
    • 경기 소식 — 득점·타석 흐름에 따라 해당 종목이 잠깐 반응
    ⚠️ 가상 포인트 게임입니다. 실제 돈·증권 거래가 아닙니다. 모바일 앱은 준비 중이며, 지금은 웹 버전입니다.
