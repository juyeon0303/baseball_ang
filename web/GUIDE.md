# 야구주식 이용 가이드

## 한 줄 소개

**야구주식**은 KBO·MLB 선수 기록과 팬 화제에 가상 포인트로 「된다 / 안 된다」를 겨루는 야구 팬 게임입니다.  
실제 주식·투자 서비스가 **아닙니다.**

---

## 뭐가 있나요?

### 1. 구단 대표 종목 (10개)

각 팀에서 화제가 된 선수 1명 = 종목 1개.

- 예: KIA 김도영, 한화 강백호, KT 힐리어드 …
- 시세 기준: 시즌 **OPS** 또는 **ERA** (KBO 공식 기록, 하루 1회 반영)

### 2. 이정후 (MLB)

- KBO 10구단과 **별도** 종목
- MLB Stats API에서 OPS 수집 (하루 1회)

### 3. 밈·화제 베팅

진지한 스탯 투자가 아니라 **팬들이 말하는 그 화제**에 베팅합니다.

| 예시 | 베팅 문구 |
|------|-----------|
| 김서현 | 직구 제구, 잡힐까? |
| 강백호 | 50홈런 간다? |
| 류현진 | 6이닝 넘길까? |

---

## 어떻게 하나요?

1. 닉네임 입력 → **10만 P**로 시작
2. 종목·밈 카드 탭
3. **된다!** = 잘 될 것 같다 · **안 된다** = 아닐 것 같다
4. 라이브 경기 때 점수판·타석 소식 확인 (연동 종목 자동 전환)
5. 주간 수익률 랭킹으로 경쟁

---

## 가격이 움직이는 이유

| 요인 | 설명 |
|------|------|
| 기록 반영 | 선수 실적(OPS/ERA) 또는 밈 지수 — 매일 갱신 |
| 된다 쪽 | 「된다」 베팅이 많아지면 시세 ↑ |
| 경기 소식 | 득점·이닝 변화 시 해당 팀 종목·밈이 잠깐 반응 |

---

## 화면 구성 (웹)

| 영역 | 내용 |
|------|------|
| 지금 베팅 | 선택한 종목 + 시세 + 된다/안 된다 비율 |
| 오늘 경기 | KBO 점수판 + 타석 한 줄 |
| 밈·화제 | 화제 베팅 목록 |
| 10개 종목 | 구단 대표 종목 전체 |
| 개발 진행 | 개발자용 중간체크 (접어 두어도 됨) |

---

## 기술 구조 (참고)

- **API** `localhost:3000` — 데이터·체결·기록 갱신
- **웹** `localhost:5173` — 지금 보는 화면
- **앱** — 별도 제품 (`app/`, 실시간 경기 앱)

## 주의

- 가상 포인트만 사용합니다.
- 경기·기록 연동은 MVP 수준이며, 전문 중계 사이트와 동일하지 않습니다.
