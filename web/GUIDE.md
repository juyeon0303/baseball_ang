# YASDAQ(야스닥) — 필수만

## 이게 뭐냐

종목·밈 골라 **「된다 / 안 된다」** 겨루는 **가상 P 게임**. 진짜 돈·주식 아님.

## 하는 법

1. 카드 탭 → 가운데 **지금 베팅**
2. **된다!** = 잘 될 듯 · **안 된다** = 아닐 듯

## 처음 한 번만

- 열면 **10만 P** 자동 (가입 버튼 없음)
- **표시 이름** — 입력 후 **칸 밖 클릭**해야 저장

## 더 필요하면

- 계정·로그인: 사이트 **「계정·로그인 상세」** 또는 레포 `AUTH.md`
- 종목 목록·시세: 화면 **10구단 / 밈·화제** 카드 보면 됨 (설명 안 읽어도 됨)
